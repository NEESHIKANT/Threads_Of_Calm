# Product image folders

Add product photos to the folder for their category:

- `home-decor/` — wall hangings, crochet pots, and other home pieces
- `bag-charms/` — crochet bag charms and accessories
- `fridge-magnets/` — crochet fridge magnets

Use simple filenames such as `Daisy Crochet Pot.png`. After adding a photo, add its product details to the matching file under `app/data/products/` (for example, `app/data/products/home-decor.ts`). Use the same filename and folder in the product's `image` path, like `/product_images/home-decor/Daisy Crochet Pot.png`.
